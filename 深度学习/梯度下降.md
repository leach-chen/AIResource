## 梯度下降（Gradient Descent）

梯度下降是机器学习中**最核心的优化算法**，用于通过不断调整模型参数来**最小化损失函数**。

---

### 核心思想

> **沿着损失函数下降最快的方向（梯度的反方向）一步步更新参数，最终走到损失函数的最低点。**

想象你站在一座山上，闭着眼想走到山脚：
- 你感知脚下哪个方向**最陡峭地向下**
- 朝那个方向迈一步
- 重复这个过程，直到到达平地

这就是梯度下降的直觉。

---

### 数学表达

假设损失函数为 \(J(\theta)\)，其中 \(\theta\) 是模型参数（如权重 \(w\) 和偏置 \(b\)）。

**梯度下降的更新公式：**

$$
\theta_{\text{new}} = \theta_{\text{old}} - \eta \cdot \nabla J(\theta_{\text{old}})
$$

其中：
- \(\nabla J(\theta)\)：损失函数的**梯度**（对所有参数求偏导数的向量）
- \(\eta\)：**学习率（Learning Rate）**，控制每一步迈多大
- 减号：因为我们要**下坡**（梯度指向上升最快的方向，反方向才是下降）

---

### 梯度下降的三种变体

| 变体 | 每次更新使用的数据量 | 特点 |
|---|---|---|
| **BGD（批量梯度下降）** | 全部训练数据 | 准确但慢，大数据集不可行 |
| **SGD（随机梯度下降）** | 1 个样本 | 快但波动大，不稳定 |
| **Mini-batch GD** | 一个小批量（如 32、64、128） | ✅ **最常用**，平衡速度和稳定性 |

---

#### 1. 批量梯度下降（Batch GD）

$$
\theta = \theta - \eta \cdot \frac{1}{N} \sum_{i=1}^{N} \nabla J_i(\theta)
$$

- 每次计算**所有样本**的梯度
- 优点：梯度方向准确，收敛稳定
- 缺点：大数据集下计算极慢

---

#### 2. 随机梯度下降（SGD）

$$
\theta = \theta - \eta \cdot \nabla J_i(\theta) \quad \text{（随机选一个样本 } i \text{）}
$$

- 每次只用**1个样本**计算梯度
- 优点：计算快，能逃离局部最优
- 缺点：梯度波动大，收敛路径不稳定

---

#### 3. Mini-batch 梯度下降（最常用）

$$
\theta = \theta - \eta \cdot \frac{1}{B} \sum_{i \in \text{batch}} \nabla J_i(\theta)
$$

- 每次用**一小批样本**（如 32、64、128）
- ✅ 兼具 BGD 的稳定性和 SGD 的速度
- ✅ 可以利用 GPU 并行计算
- **这是深度学习中最常用的方法**

---

### 学习率（Learning Rate）的重要性

学习率 \(\eta\) 是梯度下降中**最重要的超参数**：

| 学习率大小 | 结果 |
|---|---|
| **太大** | 跳过最低点，来回震荡，甚至发散（Loss 爆炸） |
| **太小** | 收敛极慢，训练时间过长 |
| **合适** | 稳步收敛到最低点 |

```
损失
  │
  │    ╲     ╱╲     ╱
  │     ╲   ╱  ╲   ╱    ← 学习率太大（震荡）
  │      ╲ ╱    ╲ ╱
  │       ╲      ╱
  │        ╲    ╱      ← 学习率合适（平滑下降）
  │         ╲  ╱
  │          ╲╱
  └─────────────────────────→ 迭代次数
```

---

### 梯度下降的挑战

| 问题 | 说明 |
|---|---|
| **局部最优** | 可能陷入局部最低点而非全局最低点（非凸问题） |
| **鞍点** | 梯度为 0 但不是最低点，参数更新停滞 |
| **梯度消失/爆炸** | 深度网络中梯度趋近 0 或无限大 |
| **选择学习率** | 过大不收敛，过慢太耗时 |

---

### 改进算法（优化器）

为了克服上述问题，发展出了多种自适应优化器：

| 优化器 | 特点 |
|---|---|
| **Momentum** | 加入"惯性"，加速收敛，减少震荡 |
| **Nesterov** | 提前看一步，更准确 |
| **AdaGrad** | 自适应学习率，稀疏特征效果好 |
| **RMSprop** | 解决 AdaGrad 学习率过快衰减的问题 |
| **Adam** | ✅ **最常用**，结合 Momentum + RMSprop |

**Adam 更新公式（简化）：**

$$
m_t = \beta_1 m_{t-1} + (1 - \beta_1) \nabla J(\theta_{t-1})
$$

$$
v_t = \beta_2 v_{t-1} + (1 - \beta_2) (\nabla J(\theta_{t-1}))^2
$$

$$
\theta_t = \theta_{t-1} - \eta \cdot \frac{m_t}{\sqrt{v_t} + \epsilon}
$$

- \(m_t\)：一阶动量（梯度均值，方向）
- \(v_t\)：二阶动量（梯度方差，自适应学习率）

### 代码示例（PyTorch）

```python
import torch.optim as optim

# 定义优化器
optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.9)

# 最常用的 Adam
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 训练循环
for epoch in range(num_epochs):
    for batch in dataloader:
        # 1. 前向传播：计算预测值
        pred = model(batch.data)
        
        # 2. 计算损失
        loss = loss_fn(pred, batch.label)
        
        # 3. 梯度清零（防止累积）
        optimizer.zero_grad()
        
        # 4. 反向传播：计算梯度
        loss.backward()
        
        # 5. 更新参数
        optimizer.step()
```
