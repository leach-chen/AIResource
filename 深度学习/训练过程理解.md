
# 房价预测模型


### 一、房价预测模型的核心思想

**一句话概括**：  
房价预测模型就是**建立一个数学公式**，把房子的多个特征（面积、卧室数、房龄等）作为输入，通过**训练**找到一组最优的权重W和偏置b，使得公式算出的预测房价尽可能接近真实房价。

**公式（线性回归）**：  
`y_pred = w₁·x₁ + w₂·x₂ + ... + wₙ·xₙ + b`

- `x₁, x₂, ..., xₙ`：输入特征（面积、卧室数、房龄等）
- `w₁, w₂, ..., wₙ`：每个特征的权重（表示该特征对房价的影响程度）
- `b`：偏置（全局修正项）
- `y_pred`：预测的房价

**训练的目的**：找到一组 `(w₁, w₂, ..., wₙ, b)`，使得对所有训练样本，`y_pred` 与真实房价 `y_true` 的误差最小。

---

### 二、训练数据长什么样？

假设我们有**4个特征**，**3个样本**：

| 样本 | 面积(x₁) | 卧室数(x₂) | 房龄(x₃) | 距地铁站距离(x₄) | 真实房价(y) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 120 | 3 | 5 | 0.8 | 300万 |
| 2 | 80 | 2 | 10 | 2.5 | 180万 |
| 3 | 150 | 4 | 3 | 0.5 | 380万 |

**输入矩阵 X**（3行×4列）：  
```
[[120, 3, 5, 0.8],
 [ 80, 2,10, 2.5],
 [150, 4, 3, 0.5]]
```

**真实标签向量 Y**（3行×1列）：  
```
[[300],
 [180],
 [380]]
```

---

### 三、模型参数（W和b）

- **权重 W**：4行×1列 `[w₁, w₂, w₃, w₄]ᵀ`
- **偏置 b**：一个标量

**总参数量**：4（权重）+ 1（偏置）= **5个参数**。

---

### 四、前向传播（Forward Propagation）

用当前的W和b，对每个样本计算预测房价：

`Y_pred = X · W + b`

**举例（初始随机值）**：  
假设 `W = [0.5, -0.2, 0.3, 0.1]ᵀ`，`b = 0.1`

- 样本1：  
  `y_pred₁ = 120×0.5 + 3×(-0.2) + 5×0.3 + 0.8×0.1 + 0.1 = 61.08万`  
  真实值300万，误差巨大。

- 样本2：  
  `y_pred₂ = 80×0.5 + 2×(-0.2) + 10×0.3 + 2.5×0.1 + 0.1 = 42.95万`  
  真实值180万。

- 样本3：  
  `y_pred₃ = 150×0.5 + 4×(-0.2) + 3×0.3 + 0.5×0.1 + 0.1 = 75.25万`  
  真实值380万。

**预测结果**：`[61.08, 42.95, 75.25]ᵀ`，全部远低于真实值，说明参数初始化很差。

---

### 五、计算损失（Loss）

使用**均方误差（MSE）**：  
`L = (1/n) · Σ(y_predᵢ - y_trueᵢ)²`

代入数值：  
`L = (1/3) × [(61.08-300)² + (42.95-180)² + (75.25-380)²]`  
`= (1/3) × [57083 + 18783 + 92872]`  
`= 56246`

**损失值 56246**，非常大，说明模型完全没学会。

---

### 六、反向传播（Backpropagation）——计算梯度

我们需要知道：**每个参数对损失的影响程度**，也就是偏导数 `∂L/∂wⱼ` 和 `∂L/∂b`。

**公式（线性回归的梯度）**：  
`∂L/∂wⱼ = (2/n) · Σ(y_predᵢ - y_trueᵢ) · xᵢⱼ`  
`∂L/∂b = (2/n) · Σ(y_predᵢ - y_trueᵢ)`

**误差向量**：`error = Y_pred - Y_true = [-238.92, -137.05, -304.75]ᵀ`

逐个计算梯度：

| 参数 | 梯度公式 | 计算结果 | 含义 |
| :--- | :--- | :--- | :--- |
| `∂L/∂w₁`（面积） | (2/3)·Σ(errorᵢ·xᵢ₁) | **-56898** | w₁增大 → 损失急剧下降，应大幅增加 |
| `∂L/∂w₂`（卧室数）| (2/3)·Σ(errorᵢ·xᵢ₂) | **-1473** | w₂增大 → 损失下降，应增加 |
| `∂L/∂w₃`（房龄） | (2/3)·Σ(errorᵢ·xᵢ₃) | **-2320** | w₃增大 → 损失下降，应增加 |
| `∂L/∂w₄`（地铁距离）| (2/3)·Σ(errorᵢ·xᵢ₄) | **-457** | w₄增大 → 损失下降，应增加 |
| `∂L/∂b`（偏置） | (2/3)·Σ(errorᵢ) | **-454** | b增大 → 损失下降，应增加 |

**所有梯度均为负**，说明当前预测值普遍偏低，需要把所有参数都往上调。

---

### 七、更新参数（Gradient Descent）

用**梯度下降**，以**学习率** `lr = 0.00001` 更新每个参数：

`wⱼ_新 = wⱼ_旧 - lr · ∂L/∂wⱼ`  
`b_新 = b_旧 - lr · ∂L/∂b`

更新结果：

| 参数 | 旧值 | 梯度 | 新值 |
| :--- | :--- | :--- | :--- |
| w₁（面积） | 0.5 | -56898 | **1.069**（大幅提升） |
| w₂（卧室数）| -0.2 | -1473 | **-0.185**（略微提升） |
| w₃（房龄） | 0.3 | -2320 | **0.323**（提升） |
| w₄（地铁距离）| 0.1 | -457 | **0.105**（提升） |
| b（偏置） | 0.1 | -454 | **0.105**（提升） |

**用新参数重新预测样本1**：  
`y_pred₁ = 120×1.069 + 3×(-0.185) + 5×0.323 + 0.8×0.105 + 0.105 ≈ 129.5万`  
误差从 -238.9万 缩小到 -170.5万，**向正确方向迈进了一步**。

---

### 八、重复迭代（直到收敛）

重复**前向传播 → 计算损失 → 反向传播 → 更新参数**，数万轮后：

| 参数 | 初始值 | 第1轮后 | 第10000轮后（收敛） |
| :--- | :--- | :--- | :--- |
| w₁（面积） | 0.5 | 1.069 | **2.0** |
| w₂（卧室数）| -0.2 | -0.185 | **10.0** |
| w₃（房龄） | 0.3 | 0.323 | **-1.0** |
| w₄（地铁距离）| 0.1 | 0.105 | **-5.0** |
| b（偏置） | 0.1 | 0.105 | **5.0** |

**验证**（样本1）：  
`120×2.0 + 3×10.0 + 5×(-1.0) + 0.8×(-5.0) + 5.0 = 240 + 30 - 5 - 4 + 5 = 266万`  
虽然还没完全等于300万，但已经比61万准确得多。如果模型足够复杂（如引入非线性特征），可以进一步逼近真实值。

---

### 九、如何预测新房子？

训练完成后，得到一组最优参数 `(w₁, w₂, w₃, w₄, b)`。  
对于一套新房，只需采集它的特征 `[面积, 卧室数, 房龄, 距地铁距离]`，代入公式即可算出预测房价。

**举例**：新房 90㎡，2室，8年房龄，距地铁1.2km  
`y_pred = 90×2.0 + 2×10.0 + 8×(-1.0) + 1.2×(-5.0) + 5.0 = 180 + 20 - 8 - 6 + 5 = 191万`

### 十、房价预测 vs 手写数字识别（本质对比）

| 对比维度 | 房价预测（线性回归） | 手写数字识别（全连接网络） |
| :--- | :--- | :--- |
| **任务类型** | 回归（预测连续值） | 分类（预测离散类别） |
| **输入** | 几个结构化特征（面积、卧室等） | 784个像素值 |
| **输出** | 1个数值（房价） | 10个概率（0~9） |
| **参数数量** | 5个（4个权重+1个偏置） | 7850个（784×10+10） |
| **损失函数** | 均方误差（MSE） | 交叉熵（Cross-Entropy） |
| **输出层激活** | 无（直接输出数值） | Softmax（转成概率） |
| **训练逻辑** | **完全相同**：前向→损失→反向→更新梯度 | **完全相同**：前向→损失→反向→更新梯度 |

### 十二、一句话终极总结

> **房价预测 = 给每个特征分配一个权重 → 加权求和算房价 → 对比真实值算损失 → 反向传播算梯度 → 同步更新所有权重 → 重复数万次 → 权重学会真实规律（面积≈2万/平，房龄每年减1万...）。** 整个过程与手写数字识别的训练逻辑**完全一致**，只是输入输出和损失函数稍有不同。😊

# 手写数字识别(全连接)

每个分数都对应784个权重，通过权重能预测出对应分数的概率，取分数最高的概率


### 1. 第一步：权重算出"原始分数"（Logits）

正如你所言，**每个分数（比如"数字1"的分数）都对应着784个权重**。

-   **数字0的分数** = 像素1×W₁₀ + 像素2×W₂₀ + ... + 像素784×W₇₈₄₀ + b₀
-   **数字1的分数** = 像素1×W₁₁ + 像素2×W₂₁ + ... + 像素784×W₇₈₄₁ + b₁
-   ...（以此类推，算出10个原始分数）

这个时候算出来的分数，比如 `[-2.3, 5.1, 0.4 ...]`，它们**还不是概率**，只是"原始得分"。它们可以是负数，可以很大，加起来也不等于1。

---

### 2. 第二步：通过 Softmax 把分数"翻译"成概率

这10个原始分数没法直接当概率用（比如 -2.3 不可能是概率）。所以我们用一个叫 **Softmax** 的数学公式，把这10个分数**拧成10个加起来等于100%的概率**。

**Softmax 的核心逻辑**：**"谁分数高，谁的概率就高；分数最高的那个，概率一定最大。"**

比如刚才的原始分数 `[-2.3, 5.1, 0.4 ...]`，经过 Softmax 转换后变成：

-   数字0的概率：0.01%（因为它的分数 -2.3 太低了）
-   **数字1的概率：80%**（因为它的分数 5.1 最高！）
-   数字2的概率：5%
-   ...

---

### 3. 第三步：取概率最高的作为预测结果

**取分数最高的，和取概率最高的，结果完全一样！**

因为 Softmax 是**单调递增**的（分数越高，转换后的概率也越高）。所以：

-   **工程上（代码实现）**：为了省去算 Softmax 的计算量，通常**直接取原始分数（Logits）最大的那个**作为预测结果。因为反正谁分高谁概率就高，没必要多算一遍指数。
-   **数学上（理论解释）**：取概率最高的那个。

**所以：权重算出分数 → 分数映射成概率 → 概率最高的就是预测结果。**（只是在代码底层，通常取的是"分数最高"）

# 手写数字识别（CNN）


### 一、CNN手写数字识别：核心思路（与全连接的“灵魂区别”）

全连接网络是把图片**压扁**成一维（784个像素），然后给**每个像素对每个数字**分配权重；  
而CNN是**保留图片的二维结构**，用**小尺子（卷积核）**在图片上滑动，**检测局部特征**（横线、竖线、圆圈等）。

| 对比维度 | 全连接网络 | CNN |
| :--- | :--- | :--- |
| 输入处理 | 拉直成784个像素，丢失位置关系 | 保留28×28结构，保留“横竖撇捺”的空间位置 |
| 参数形式 | 一个大表格（784×10） | 多个小尺子（3×3卷积核） |
| 参数数量 | 7850个 | 约5万个（但效果更好、更鲁棒） |
| 识别逻辑 | 记住每个位置的像素分布 | 先找“零件”（横线/圆圈），再组合判断 |
| 抗偏移能力 | 差（数字偏一点就认不出） | 强（尺子能滑到任何位置找到特征） |
| 准确率 | ~92% | ~99%+ |

核心思想：**全连接是“死记硬背”，CNN是“理解结构”。**

---

### 二、CNN的输入与输出

- **输入**：一张 **28×28** 的灰度图（每个像素值0~1），保留二维结构。
- **输出**：10个概率（分别表示0~9的可能性）。

---

### 三、CNN的“零件识别”过程（前向传播）

CNN不是一步到位，而是**分层提取特征**，越往后特征越抽象。

| 阶段 | 做了什么 | 输入→输出尺寸 | 得到了什么 |
| :--- | :--- | :--- | :--- |
| **卷积层1** | 用 **6个3×3小尺子** 在图上滑动，检测局部模式 | 28×28 → 6张26×26特征图 | 横线、竖线、边缘等简单特征 |
| **池化层1** | 对每张特征图做 **2×2取最大值**，缩小尺寸 | 26×26 → 13×13 | 保留最强特征，去除冗余信息 |
| **卷积层2** | 用 **16个3×3×6立体尺子** 在6张图上同时滑动，检测更复杂模式 | 13×13 → 16张11×11特征图 | 拐角、圆弧、交叉点等组合特征 |
| **池化层2** | 再次 2×2 取最大值 | 11×11 → 5×5 | 继续压缩，保留最关键信息 |
| **展平** | 把16张5×5特征图拉直成一维 | 16×5×5 = **400个特征** | 所有“零件清单”汇总 |
| **全连接层** | 把400个特征组合起来，映射到10个数字 | 400 → 120 → 10 | 综合判断是哪个数字 |

**关键理解**：  
- 卷积层是“找零件”（横线、圆圈）；  
- 全连接层是“组装零件做决策”（有横线+有圆圈→可能是8）。

---

### 四、CNN里的“W和b”长什么样？

CNN的参数仍然是W和b，只是组织形式不同：

| 参数 | 形状 | 数量 | 作用 |
| :--- | :--- | :--- | :--- |
| **卷积层1的卷积核** | 6个 3×3 小矩阵 | 6×9=54 | 检测横线、竖线等 |
| **卷积层1的偏置** | 6个 | 6 | 每个特征图一个偏置 |
| **卷积层2的卷积核** | 16个 3×3×6 立体核 | 16×54=864 | 检测拐角、圆弧等 |
| **卷积层2的偏置** | 16个 | 16 | 每个特征图一个偏置 |
| **全连接层权重** | 400×120 和 120×10 | 48000+1200 | 组合特征做决策 |
| **全连接层偏置** | 120 和 10 | 130 | — |
| **总计** | — | **约5万个** | — |

**注意**：CNN的参数数量**远少于**把400个特征直接全连接到10个类别的简单做法（400×10=4000），因为CNN通过权重共享和分层抽象，用更少的参数学到了更鲁棒的特征。

---

### 五、为什么CNN更擅长识别手写数字？

| 传统全连接的问题 | CNN如何解决 |
| :--- | :--- |
| 数字稍微偏移就认不出 | 卷积核在整张图上滑动，**平移不变**，不管偏哪都能扫到 |
| 参数太多，容易过拟合 | 权重共享，参数量更少，泛化能力更强 |
| 无法理解局部结构 | 分层提取特征，先找横线再组合，更符合人类视觉 |
| 对噪声敏感 | 池化层取最大值，过滤掉微弱噪声 |

---

### 六、CNN的训练过程（与全连接完全相同）

训练CNN和训练全连接网络**流程完全一样**，只是求导的对象变成了卷积核里的参数：

1. **前向传播**：用当前卷积核和全连接权重，算预测概率。
2. **计算损失**：交叉熵，衡量预测和真实标签的差距。
3. **反向传播**：从输出层往回推，计算**每个卷积核里的每个数字**对损失的梯度。
4. **更新参数**：`W_新 = W_旧 - 学习率 × 梯度`，所有参数同步更新。

**关键点**：卷积核的梯度来自它滑动过的**所有位置**，把这些位置的梯度累加起来，统一更新这个核——这就是**权重共享**在反向传播中的体现。

---

### 七、最终一句话总结

> **CNN手写数字识别 = 用多个小尺子在图上滑动找零件（卷积）→ 压缩精华（池化）→ 列出零件清单（展平）→ 组装零件做判断（全连接）。训练过程和全连接一样，都是“前向算损失 → 反向算梯度 → 梯度下降更新参数”，只是参数变成了“小尺子里的数字”，并且通过权重共享实现了平移不变性。** 😊

       ├──→ ...（共10组，互不共享）
       └──→ 评委9 (W₉: 784个权重 + b₉) ──→ 分数9

  总参数：784×10 + 10 = 7850个


┌─────────────────────────────────────────────────────────────────────────────┐
│                   数字识别（CNN）：共享卷积核 + 1组全连接                  │
│                         输出10个分数                                       │
└─────────────────────────────────────────────────────────────────────────────┘

       │
       ├──→ 横线检测尺(3×3) ──→ 特征图1 ──┐
       ├──→ 竖线检测尺(3×3) ──→ 特征图2 ──┤

## 一句话总结

> **房价预测 = 1组 (W,b)**（5个参数，算1个房价）  
> **全连接数字识别 = 10组独立的 (W,b)**（7850个参数，算10个分数）  
> **CNN数字识别 = 共享卷积核 + 1组全连接 (W,b)**（约5万个参数，先提特征再算10个分数）  

三者的共同点：**训练过程完全一样（前向→损失→反向→更新）**，区别只在于 **参数的组织方式和数量**。😊
