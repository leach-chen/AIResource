## 激活函数（Activation Function）

激活函数是神经网络中**引入非线性的关键**，如果没有激活函数，多层神经网络就等价于一个线性变换，无法拟合复杂的数据分布。

---

### 为什么需要激活函数？

回顾最开始的说明：

> 如果没有非线性激活函数，无论堆叠多少层，最终都是线性变换：
> 
> $$
> y = x_1 - x_2 + x_3 + x_4
> $$
> 
> 无法学习 XOR、图像、语音等复杂的非线性关系。

**激活函数的作用：**
- ✅ 引入**非线性**，使神经网络能拟合任意复杂函数
- ✅ 决定神经元是否被"激活"（输出是否传递到下一层）
- ✅ 将输出压缩到特定范围（如 0~1）用于概率解释

---

### 常用激活函数

---

#### 1. Sigmoid（S 型函数）

$$
\sigma(x) = \frac{1}{1 + e^{-x}}
$$

**输出范围：** \((0, 1)\)

**特点：**
- ✅ 输出可解释为概率（用于二分类输出层）
- ✅ 平滑、处处可导
- ❌ 梯度消失问题（两端导数接近 0）
- ❌ 输出不是零中心（全为正，影响梯度更新效率）
- ❌ 计算较慢（含指数运算）

**适用场景：** 二分类输出层（配合交叉熵损失）

```
Sigmoid 图像：
  1 │         ╭──────
    │       ╱
    │     ╱
  0.5│   ╱
    │ ╱
    │╱
  0 └─────────────────
     -6  -3   0   3   6
```

---

#### 2. Tanh（双曲正切）

$$
\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} = 2\sigma(2x) - 1
$$

**输出范围：** \((-1, 1)\)

**特点：**
- ✅ 零中心输出（均值为 0），利于梯度更新
- ✅ 比 Sigmoid 梯度更大（两端更陡）
- ❌ 仍有梯度消失问题
- ❌ 计算较慢

**适用场景：** 传统 RNN / LSTM 中常用

```
Tanh 图像：
  1 │       ╭──────
    │     ╱
    │   ╱
  0 │──╱────────────
    │╱
 -1 │╯
    └─────────────────
     -6  -3   0   3   6
```

---

#### 3. ReLU（Rectified Linear Unit）

$$
\text{ReLU}(x) = \max(0, x)
$$

**输出范围：** \([0, \infty)\)

**特点：**
- ✅ 计算极快（仅比较大小）
- ✅ 缓解梯度消失（正区间梯度恒为 1）
- ✅ 稀疏激活（部分神经元输出为 0）
- ❌ 输出不是零中心
- ❌ Dead ReLU 问题（神经元永久输出 0）

**适用场景：** ✅ **深度学习中默认首选**（CNN、MLP 隐藏层）

```
ReLU 图像：
  y │        /
    │       /
    │      /
    │     /
  0 │────/────────
    │  /
    │ /
    └─────────────────
       0   x →
```

---

#### 4. Leaky ReLU

$$
\text{Leaky ReLU}(x) = \begin{cases}
x & \text{if } x > 0 \\
\alpha x & \text{if } x \leq 0
\end{cases}
$$

其中 \(\alpha\) 是一个小常数（如 0.01）

**特点：**
- ✅ 解决 Dead ReLU 问题（负数也有梯度）
- ✅ 计算快
- ❌ 需要额外调参 \(\alpha\)

**改进版：** **PReLU**（\(\alpha\) 可学习）、**ELU**（负数部分呈指数衰减）

```
Leaky ReLU 图像：
  y │        /
    │       /
    │      /
    │     /
  0 │────/───
    │  ╱
    │ ╱   (有微小斜率)
    │╱
    └─────────────────
       0   x →
```

---

#### 5. Softmax

$$
\text{Softmax}(x_i) = \frac{e^{x_i}}{\sum_{j=1}^{C} e^{x_j}}
$$

**输出范围：** \((0, 1)\)，且所有输出和为 1

**特点：**
- ✅ 输出为概率分布，可解释性强
- ✅ 保持相对大小关系
- ❌ 指数运算可能导致数值溢出（需减去最大值）

**适用场景：** **多分类输出层**（唯一选择）

---

### 激活函数总结对比

| 激活函数 | 输出范围 | 优点 | 缺点 | 适用场景 |
|---|---|---|---|---|
| **Sigmoid** | (0, 1) | 概率解释、平滑 | 梯度消失、非零中心、慢 | 二分类输出层 |
| **Tanh** | (-1, 1) | 零中心 | 梯度消失、慢 | RNN/LSTM |
| **ReLU** | [0, ∞) | 快、缓解梯度消失 | Dead ReLU、非零中心 | ✅ 隐藏层默认首选 |
| **Leaky ReLU** | (-∞, ∞) | 解决 Dead ReLU | 需调参 | ReLU 不佳时尝试 |
| **Softmax** | (0,1) 和为1 | 概率分布 | 数值稳定性需注意 | ✅ 多分类输出层 |

---

### 如何选择激活函数？

| 位置 | 推荐 |
|---|---|
| **隐藏层** | **ReLU**（默认首选），效果不好再试 Leaky ReLU / ELU |
| **二分类输出层** | **Sigmoid** |
| **多分类输出层** | **Softmax** |
| **回归输出层** | **无激活函数**（线性输出） |
| **多标签分类输出层** | **Sigmoid**（每个标签独立） |

---

### 梯度消失与 ReLU

- **Sigmoid/Tanh** 在两端导数接近 0，深层网络中梯度逐层衰减，导致前层参数几乎不更新 → **梯度消失**
- **ReLU** 在正区间梯度恒为 1，信号能有效传回前层 → 成为深度学习主流选择

---

### 代码示例（PyTorch）

```python
import torch.nn as nn

# 定义带激活函数的网络
class MyNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 256)
        self.relu = nn.ReLU()              # 隐藏层用 ReLU
        self.fc2 = nn.Linear(256, 128)
        self.fc3 = nn.Linear(128, 10)
        self.softmax = nn.Softmax(dim=1)   # 多分类输出层用 Softmax
    
    def forward(self, x):
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        x = self.softmax(self.fc3(x))      # 输出概率分布
        return x
```
