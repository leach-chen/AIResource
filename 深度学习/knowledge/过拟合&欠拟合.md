## 过拟合与欠拟合

这是机器学习中最核心的两个概念，直接关系到模型能否"举一反三"。

---

### 核心定义

| | **欠拟合（Underfitting）** | **过拟合（Overfitting）** |
|---|---|---|
| **通俗理解** | 学得太差，连训练数据都没学好 | 学得太死，只记住了训练数据，不会举一反三 |
| **本质** | 模型能力不足，没捕捉到数据规律 | 模型把噪声也当成了规律 |
| **训练集表现** | 差（准确率低/误差大） | 好（几乎完美） |
| **测试集/新数据表现** | 差（同样差） | 差（远不如训练集） |
| **偏差-方差** | 高偏差 | 高方差 |

---

### 直观类比

> **欠拟合**：像一个小学生去考高考数学，知识储备不够，题目做不对（训练集都做不好）。
>
> **过拟合**：像一个人把整本习题集的答案都背下来了，但题目稍微换个数就不会做了（训练集全对，新题不会）。

---

### 如何判断

| 观察 | 结论 |
|---|---|
| 训练集误差**高**，测试集误差**高** | **欠拟合** |
| 训练集误差**低**，测试集误差**低** | ✅ 理想状态 |
| 训练集误差**低**，测试集误差**高** | **过拟合** |
| 训练集误差**高**，测试集误差**更低**（罕见） | 数据异常或模型不稳定 |

---

### 原因分析

| 欠拟合原因 | 过拟合原因 |
|---|---|
| 模型太简单（层数少、参数少） | 模型太复杂（参数过多） |
| 训练不够（epoch太少） | 训练太久（epoch过多） |
| 特征太少或特征质量差 | 训练数据太少 |
| 正则化太强 | 数据噪声大 |
| 学习率太低 | 未使用正则化或正则化太弱 |

---

### 解决方法

#### 欠拟合的解决方案

| 方法 | 说明 |
|---|---|
| **增加模型复杂度** | 加更多层、更多神经元 |
| **增加更多特征** | 做特征工程，加入有用特征 |
| **减少正则化** | 降低 L1/L2 系数，减少 Dropout |
| **训练更久** | 增加 epoch 数 |
| **调高学习率** | 让模型收敛更快 |
| **尝试更复杂模型** | 如从线性模型换到神经网络 |

#### 过拟合的解决方案

| 方法 | 说明 |
|---|---|
| **增加训练数据** | 收集更多样本或做数据增强 |
| **降低模型复杂度** | 减少层数或神经元数 |
| **正则化** | L1/L2 正则化、Dropout |
| **早停（Early Stopping）** | 验证集误差不再下降时停止训练 |
| **数据增强** | 图像翻转、裁剪、旋转等 |
| **交叉验证** | 用 K 折验证选择最佳超参数 |
| **简化特征** | 特征选择，删除无关特征 |

---

### 正则化的直观理解

> **L2 正则化（权重衰减）**：给损失函数加上 \(\lambda \sum w^2\)，惩罚大的权重。迫使模型"平均用力"，不依赖少数几个特征。
>
> **Dropout**：训练时随机关闭一部分神经元（比如 50%），迫使网络学会多条独立路径，避免协同过拟合。
>
> **Early Stopping**：监控验证集误差，一旦开始上升就停，在过拟合发生前截停。

---

### 一个实际例子

> 用神经网络预测房价，只有 100 条数据，用了 10 层网络、每层 1000 个神经元。
>
> - 训练集误差：接近 0（几乎完美记忆了每套房子的价格）
> - 测试集误差：巨大（新房子完全预测不准）
>
> **这就是典型的过拟合**——模型记住了具体数据而不是学会了规律。

---

### 与之前全连接层的关联

全连接层参数量大，是**过拟合的高风险区域**。这就是为什么：
- CNN 用卷积层代替全连接来处理图像（参数更少）
- 分类网络最后用全连接层之前，通常先做 **全局平均池化（Global Average Pooling）** 来降维
- Dropout 通常加在全连接层之后
